# 交付前检查清单

逐镜对照 `out/review/<id>/sheet_*.jpg`，每一项都要过。

## 内容
- [ ] 每个答案都和原文一致；改写/合并/补充已记下，交付时列给用户
- [ ] 没有原文之外的推断
- [ ] 示意数据标了“示意”
- [ ] 字幕里数字是阿拉伯数字（subs_map 生效），配音读法正确

## 画面
- [ ] 每一帧左上角有品牌标签（封面、片尾卡除外），右上角栏目 · 期数 · 章节
- [ ] 文字没有溢出、没有单字换行（孤字）
- [ ] 元素之间、元素与字幕条之间有留白，没有相撞
- [ ] 每个问答镜头都有“演出来”的画面，而不只是文字
- [ ] 主角各步动作不重复
- [ ] 新姿势已用 PoseSheet / ItemSheet 检查
- [ ] 深色底镜头已加进 Film.tsx 的 DARK
- [ ] 没有金色、渐变色块、整屏扫过的转场

## 动效（看半分辨率试渲染的 draft.mp4）
- [ ] 背景图案滚动平滑，不抖、不跳
- [ ] 跑/走姿势自然
- [ ] 元素在说到对应的词时出现（cue 对齐）

## 声音
- [ ] 每句配音 char alignment 100%
- [ ] 导出后响度 −14 LUFS（render.sh 会打印）

## 交付
- [ ] mp4 + srt + 压缩版都在 out/
- [ ] 告诉用户：文件位置、时长、结构表、核对清单，声音请用户亲自听
