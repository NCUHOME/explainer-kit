# 教务答疑直通车 · 动画视频套件

把一份通知、办事指南或常见问题文档，交给 Claude Code，做成带南昌大学教务处品牌、AI 配音、字幕和原创配乐的动画说明视频。

用它做出的成片：「教务答疑直通车」第六期《学生体质健康标准》Q&A（补测篇）、第七期（缓免测篇）。这两期的全部源码在 `video/src/episodes/bu/` 和 `hm/`，可以直接打开看、改、重新导出。

> 你不需要会写代码。你要做的是：**准备好材料 → 用下面的提示词告诉 Claude 做什么 → 看成片、提意见**。写代码、配音、配乐、导出都由 Claude 按内置的 skill（`.claude/skills/explainer-video/`）完成。

## 一、第一次使用：安装（只需一次）

| 软件 | 用途 | 安装 |
|---|---|---|
| Claude Code | 做视频的“同事” | https://claude.com/claude-code （需要 Claude 账号） |
| Node.js 20 以上 | 渲染画面 | https://nodejs.org （选 LTS） |
| ffmpeg | 合成视频、处理声音 | macOS：`brew install ffmpeg` · Windows：`winget install ffmpeg` |
| Python 3.10 以上 | 配音、配乐 | https://www.python.org/downloads/ |
| pandoc（可选） | 读取 Word 文档 | macOS：`brew install pandoc` |

```bash
git clone https://github.com/NCUHOME/explainer-kit.git
cd explainer-kit
./setup.sh        # 约 2 分钟，装好会提示“完成”
claude            # 在这个文件夹里打开 Claude Code
```

> Windows 同学：脚本按 macOS / Linux 写，请在 WSL 里使用。
> 配音用的是微软在线语音，制作时需要联网。

## 二、开工前准备这些信息

一次给全，Claude 就能一口气做完；缺了它会在开工前一次性问你。

| 信息 | 必需？ | 说明 / 示例 |
|---|---|---|
| **原始文档** | 必需 | .docx / .pdf / .txt，写上文件路径。这是答案的唯一来源 |
| **本期做哪一部分** | 必需 | 例如「只做文档里的『补测』一章」。一章一期，2–3 分钟最合适 |
| **期数 + 篇名** | 必需 | 例如「第八期 · 选课篇」 |
| **完整标题** | 必需 | 例如「教务答疑直通车｜第八期：南昌大学本科生选课 Q&A（选课篇）」，也会用作文件名 |
| **封面副标题** | 建议 | 例如「南昌大学本科生选课 Q&A」 |
| **截图 / 照片** | 可选 | 相关 APP、网站的截图（手机截图直接给就行，会自动裁剪、放大局部） |
| **口径说明** | 建议 | 文档里说法不一致、或和实际系统不一致的地方，以哪个为准。例如「以『APP 不受理线上申请』为准」 |
| **要不要先看分镜** | 可选 | 想先确认结构就说“先给我分镜”；赶时间就说“直接做完给成片” |
| **偏好** | 可选 | 时长、声音（默认晓伊女声）、哪些问题必须保留 |

单位、栏目名、标志、品牌色已经预设为「南昌大学 教务处 · 教务答疑直通车」，不用再给。要换成别的单位或栏目，见第五节。

## 三、提示词模板（直接复制，改掉【】里的内容）

### 1. 做一期新视频（最常用）

```text
用这份文档做一期视频：【/Users/xxx/Downloads/选课常见问题.docx】

- 只做文档里的【「选课」】这一章
- 期数：【第八期】，篇名：【选课篇】
- 完整标题：【教务答疑直通车｜第八期：南昌大学本科生选课 Q&A（选课篇）】
- 封面副标题：【南昌大学本科生选课 Q&A】
- 截图素材：【/Users/xxx/Desktop/截图1.jpg、截图2.jpg】（没有就删掉这行）
- 口径：【文档第 3 条和教务系统不一致时，以文档为准】（没有就删掉这行）

【直接做完，给我成片】/【先给我分镜，确认后再做】
```

### 2. 先看分镜，确认后再做

```text
先不要做动画。读完文档后，给我这一期的分镜方案：分几部分、每个问题用什么画面演出来、配音稿全文，
并列出你改写或合并过的句子让我核对。我确认后你再开始做。
```

确认时直接回复，例如：“第 3 问的画面换成流程图；第 5 问删掉；其他没问题，开始做。”

### 3. 看完成片后提修改意见

说清楚**时间点或镜头**，再说**哪里不对、想要什么效果**：

```text
几处修改：
1. 0:35 那个镜头文字太挤，和下面的线贴在一起了，留点空
2. 1:12 第 4 问的答案说错了，原文是「……」，按原文改
3. 小人跑步姿势不自然，像瘸腿
4. 整体蓝色太深，浅一点
5. 配音太平，没有起伏
改完重新导出成片
```

- 截一张图贴给 Claude，比文字描述更准。
- 通用的意见（比如“不要用金色”“排版要留白”）Claude 会记进 `LESSONS.md`，以后每一期都会遵守。

### 4. 只改字幕或配音的某一句

```text
第 6 个镜头的配音改成「……」，字幕同步改，其他不动，重新导出。
```

### 5. 重新导出 / 只要压缩版

```text
重新导出第八期成片，并给我一个适合发微信群的压缩版。
```

### 6. 继续上次没做完的

```text
继续做第八期。先看一下 video/src/episodes/ 里这一期做到哪了，从没完成的地方接着做。
```

## 四、一期视频是怎么做出来的

| 步骤 | 谁来做 | 你需要做什么 |
|---|---|---|
| 1. 读文档，按同学办事的先后顺序排问题，分成 3–4 部分 | Claude | 想先看就要分镜（模板 2） |
| 2. 写配音稿（数字会写成读法，字幕里再换回阿拉伯数字） | Claude | —— |
| 3. 生成配音、节拍时间轴、原创配乐 | Claude | —— |
| 4. 做动画：每个问题都有画面把答案“演”出来 | Claude | —— |
| 5. 截帧自查：溢出、相撞、留白、姿势、事实 | Claude | —— |
| 6. 导出 mp4 + 字幕 + 压缩版 | Claude（约 10 分钟） | —— |
| 7. **审片** | **你** | **亲自听声音**（Claude 听不到）、核对 Claude 列出的改写句、提修改意见（模板 3） |

成片在 `out/` 文件夹：

- `标题.mp4`：1080p 成片
- `标题.srt`：字幕文件，上传视频平台时用
- `标题_压缩版.mp4`：发微信群用

想在浏览器里拖动时间轴逐帧看，可以对 Claude 说“打开预览”，或者自己运行 `cd video && npx remotion studio`。

## 五、换单位 / 换栏目

所有品牌设置都在一个文件夹：`video/public/brand/`

- `brand.json`：单位名（org）、部门（dept）及英文名、栏目名（series）、品牌色（primary，五个色阶，深→浅）、片尾免责声明（disclaimer）
- 官方组合标志两张：浅色底用（lockupColor）、深色底用的反白版（lockupWhite）。没有图片就把这两项留空，会自动用文字排版

也可以直接告诉 Claude：

```text
这次是学生处的栏目「学生事务小课堂」，标志在【/路径/logo.png】，主色用紫色，帮我改好品牌设置。
```

## 六、常见问题

**做一期要多久？** 从给材料到拿到成片，通常 1–2 小时，其中导出约 10 分钟。需要改几轮的话另算。

**Claude 说的内容能直接用吗？** 答案只从你给的文档里取，但**发布前一定要核对**。Claude 交付时会列出所有改写、合并、补充过的句子，还有示意数据（比如成绩卡上的分数），请逐条确认。

**数字读错了怎么办？** 告诉 Claude 哪句读错了。配音稿里数字要写成读法（例如“二零二四级”“三九二、四六七、五四四”），Claude 会处理。

**报错了怎么办？** 把终端里的报错整段贴给 Claude，说“帮我修好”。

**文件太大发不出去？** 用 `_压缩版.mp4`（2–3 分钟的视频大约 15MB）。

## 附：文件夹结构

```
.claude/skills/explainer-video/   Claude 的做法：SKILL.md（流程）+ references/（视觉规范、组件目录、审片意见、检查清单）
video/public/brand/               品牌配置和标志
video/src/episodes/<id>/          每一期：配音稿、镜头表、画面代码（bu = 补测篇，hm = 缓免测篇）
video/src/picto/ · video/src/kit/ 画面组件（象形小人、图案、封面、章节卡、问答头、流程节点……）
tools/                            配音、时间轴、配乐、截帧检查、导出脚本
out/                              导出的成片（不上传到仓库）
```

手动命令（一般不需要，Claude 会自己用）：

```bash
.venv/bin/python tools/new_episode.py <id> --episode 第八期 --tag 选课篇 --subtitle "…" --title "…"
tools/audio.sh <id>                  # 配音 + 节拍时间轴 + 原创配乐
tools/review.sh <id>                 # 半分辨率试渲染 + 截帧拼图（out/review/<id>/）
tools/render.sh <id> "<完整标题>"     # 最终导出 mp4 + srt + 压缩版
```
