# 风格说明书：象形说明书（Pictogram How-to）

> 本套件所有视频共用的视觉规范。画面先按这份文件设计，再动手做镜头。
> 首个成片：南昌大学教务处「教务答疑直通车」第六期（补测篇）、第七期（缓免测篇）。
> 语法参考（只学语法，不抄任何具体作品）：lemo-opuscar 的 Pictogram Motion（几何象形小人 + 方格图案系统 + 大字排版 + 节拍锁定）与 Mid-century Cartoon（说明书式分步：编号圆章、圆形放大框、细节标签、对错分屏）。二者均为 MIT 协议。

## 1. 本质

一部**会动的体测说明书**。每个信息点都要有一个画面把它"演"出来：一个象形小人做一个动作，或一个圆形放大框里出现一个真实界面；文字只做标题和标签，**信息落在画面上，不做成幻灯片**。

一眼能认出的四个特征：
1. **方格图案**：以画面高度 1/6（180px）为格，格里是大圆、半圆、四分之一圆、同心弧、跑道分道线等几何纹样，同一色相的五个色阶；整行会左右错位滑动。
2. **象形小人**：无脸、圆头、圆角粗线条的肢体，远侧肢体颜色更靠近背景。人站在一个"太阳圆盘"上。
3. **字即建筑**：中文标题用思源黑体 900 超大字号；数字和英文用 Inter Tight 900；角落有 DM Mono 等宽小字，像体育转播的 HUD。
4. **说明书语法**：每一步有编号圆章；细节进入圆形放大框；提示用带星号的纸卡标签。

不是什么：不是 PPT（不堆列表）、不是卡通（小人没有表情）、不是科技风（没有发光、玻璃、渐变色块）、不是花哨（转场只用格子本身的动作）。

## 2. 色彩逻辑

- **四个色相 × 五个色阶 + 一个深色中性 + 一个米白 + 一个墨色**。一个章节 = 一个色相。
  | 色相 | 用途 | 最深 → 最浅（中间为基色） |
  |---|---|---|
  | 品牌色（brand.json → primary；南大蓝示例） | 第一章 体测预约；片头片尾；品牌标签与字幕条固定用基色 `#2658C4` | `#1B3F8F` `#2658C4` `#4F80DE` `#A3BDEE` `#E0E9FA` |
  | 跑道红 | 第二章 体质测试 | `#7A2820` `#B23A2F` `#D4483B` `#EC9A8F` `#F8D8D2` |
  | 草场绿 | 第三章 成绩与规则 | `#1D5236` `#2C7A4E` `#3F9A66` `#98CFAB` `#DAEFE1` |
  | 湖水青 | 下集 缓免测 | `#0C566B` `#157E98` `#2BA2BF` `#8ED2E2` `#D5EFF5` |
  | 深色中性 | 警示卡、静默时刻 | `#15181F` |
  | 米白 / 墨色 | 所有色相共用的文字色 | `#F6F2EA` / `#15181F` |
- 深色调上用米白字，浅色调上用墨色字。**不用金色，不用渐变色块**；唯一允许的渐变是太阳圆盘上一道很淡的高光扫过。
- 红色同时承担"注意"语义：警示信息用深色中性底 + 跑道红强调。

## 3. 字体与字幕

- 标题：思源黑体 900，150–240px，字距略收。
- 数字 / 英文：Inter Tight 800–900；大号空心数字（描边）做章节号。
- HUD：DM Mono 22px，字距加宽，四角放置：左上"南昌大学教务处 · 教务答疑直通车 EP.04"，右上"CH.0x / 03 · 章节名"，底部一条刻度进度条（当前项高亮，已完成变暗）。
- 字幕：底部一条章节色的实色字条，思源黑体 500，40px，米白字；**永远不压在标题或小人上**。停留时长 ≥ max(1.8s，语音时长 + 0.6s)。
- 文字入场：从遮罩里向上滑出；标题先，副标题晚 0.08s，标签再晚。

## 4. 象形小人

- 单位 = 身高 H。躯干粗 0.11H，四肢粗 0.075H，圆头半径 0.075H，全部圆角端点。
- 先画远侧肢体（向背景色混合约 40%），再画躯干、近侧肢体、头。
- 每个体测项目一个动词：跑、跳、伸、拉、坐起、吹气、站上秤。动作有预备、发力、收势，关键帧落在节拍上。
- 讲步骤时，身体保持静止，**只有手在动**（Mid-century 语法）：点屏幕、举证件、递材料。

## 5. 动效质感

- 一个速度网格：BPM 112。每个镜头在拍点开始，每个关键动作（起跳、落地、盖章）落在整拍上。
- 入场：指数缓出；换镜：格子整行滑动、整列落下、四分之一圆从格角展开、从最后一个小人圆盘做圆形转场。**不用淡入淡出，不用整屏跑道扫过**。
- 背景会"呼吸"：图案行以极慢速度左右交替漂移。
- 弹出元素（圆章、标签）可用一次回弹缓动，全片克制使用。

## 6. 镜头语法

| 运镜 | 表达什么 | 用在 |
|---|---|---|
| 锁定平面构图 | 清楚，像一张海报 | 需要读的规则、数字 |
| 推进一个格子直到它成为下一画面 | 从整体进入细节 | 章节卡 → 第一张内容卡 |
| 横向跟拍，一拍一甩 | 一组连续项目 | 七个体测项目 |
| 拉远成一面图标墙 | 全部一起看 | 章节小结、片尾回顾 |
| 圆形放大框 + 引线 | 同时给出位置和细节 | APP 界面、证件 |
| 沿格线分屏 | 对比 | 最新 vs 最好、对 vs 错 |
| 静止 ≥ 3 秒 | "截图保存这一帧" | 申诉 QQ 群、分数门槛 |

## 7. 声音

- 三层：环境（体育馆的空间感，极轻）、拟音（跟动作绑定）、音乐（以打击乐为骨架：军鼓、拍手、木鱼，加马林巴和拨弦做旋律色彩）。
- 体测专属拟音：发令枪/哨子（章节开始）、秒表滴答（讲时间）、球鞋摩擦（跑）、垫子闷响（落地）、盖章声（圆章）、手机点击（APP）。
- **静默是工具**：讲"离场即终止""视为放弃"之前，整条音轨静半拍，第一个回来的声音就是重点。
- 混音：配音比音乐高约 10dB，拟音不压低，整片 −14 LUFS。

## 8. 招牌镜头示例（体测系列）

**七个体测项目的"象形连播"**：镜头横向跟拍，一拍一个项目，七个小人依次完成各自的动作（跑、跳、伸、拉、坐起、吹气、站上秤），最后拉远成一面七宫格图标墙，墙上标出"室内 ×3 次 / 室外 ×1 次"。

## 9. 常见坑

- 小人太小或贴边 → 关键时刻主体至少占画面高度 1/3。
- 同色叠同色（红底红字）→ 按第 2 节的深浅规则。
- 字幕压到主体 → 字幕条区域留空。
- 截图里的小字看不清 → 一律放进圆形放大框，放大到原生尺寸。
